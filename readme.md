# 🚀 LocalScript AI Agent

Локальная агентская система для генерации, валидации и итеративного улучшения Lua-скриптов под платформу LowCode. 

Решение создано в рамках хакатона. Полностью изолировано, не использует внешние API (OpenAI/Anthropic) и работает строго в контуре (Local & Secure).

## 🛠 Архитектура и Киллер-фичи

1. **Многошаговая валидация (LangGraph)**: 
   Генерация -> Синтаксическая проверка (`luac`) -> Статический анализ (`luacheck` с учетом глобальных переменных платформы `wf`). Если найдены ошибки, агент делает до 3 попыток автоматического исправления (Self-Reflection).
2. **Stateless Память и Итерации**: 
   Бэкенд не хранит тяжелые сессии или базы данных. "Память" агента живет на стороне клиента (Context API), что позволяет юзеру итеративно дорабатывать код (например: *"добавь в эту функцию проверку на ноль"*), отправляя прошлый результат в поле `context`.
3. **Keyword-based RAG (База знаний)**: 
   Вместо тяжеловесных векторных БД (которые потребляют VRAM), мы реализовали алгоритм умного скоринга по тегам. Шаблоны из `templates.json` инжектятся в LLM через строгие XML-теги, заставляя модель следовать корпоративным стандартам написания кода.
4. **Защита от галлюцинаций**: 
   При неоднозначных запросах или попытке доработать несуществующий код, агент возвращает уточняющий вопрос в виде валидного Lua-комментария (`-- Пожалуйста, предоставьте исходный код`), не ломая парсеры авто-тестов.

## ⚙️ Технические требования и параметры (Строго по ТЗ)

Система оптимизирована для работы на GPU с ограничением **≤ 8.0 GB VRAM**. 

* **Модель:** `qwen2.5-coder:7b`
* **Движок:** Ollama (встроен в docker-compose)
* **Параметры генерации:** `num_ctx=4096`, `num_predict=256`
* **Параметры Ollama:** `OLLAMA_NUM_PARALLEL=1`, `OLLAMA_MAX_QUEUE=1`

##
